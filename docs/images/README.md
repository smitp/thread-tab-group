# Authentic Thread screenshots

Captured from the unchanged Thread 0.2.1 extension in a clean, headed Firefox 160.0a1 profile on macOS. Nightly was used for capture, not required by Thread.

- [Groups](01-groups.png): real bundled on-device inference formed Kyoto Travel (3 tabs) and JavaScript (3). A manually created Read later group (2) and one pinned tab remained intact.
- [Reject and retry](02-reject.png): Kyoto Travel was deliberately rejected to demonstrate correction. All nine tabs stayed open; the three released tabs waited for the next explicit organizing action.
- [Settings](03-settings.png): activity learning was off and Firefox-native AI permission had not been granted. This view was captured before rejection.

The nine sample tabs were public documentation/travel pages from MDN, Firefox.com, Japan Guide, Wikivoyage, Wikipedia, javascript.info, and W3Schools. No personal profile, account, or browsing data was used.

Each presentation image is 1600×1200, made from a 2× toolbar-panel capture. Only surrounding headings, padding, borders, and shadows were added. Embedded UI pixels were not resized or altered; names and results were not fabricated. Pixel comparisons verified the raw captures against the embedded panels and the saved AMO images against these presentation images.

These selected examples demonstrate the interface, not general grouping accuracy, a complete compatibility test, or Mozilla approval.
